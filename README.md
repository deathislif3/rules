# rules - Loon & Surge Mirror

Personal mirror of only the `rule/Loon` and `rule/Surge` folders from
[blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script).

- Synced automatically every day by GitHub Actions (`.github/workflows/sync-loon-surge.yml`)
- All rules belong to the original authors / upstream project; this repo is just a selective mirror for personal use.
- Upstream license: GPL-2.0 (see upstream repository)

Raw usage example:
```
https://raw.githubusercontent.com/deathislif3/rules/main/rule/Loon/<Category>/<Name>.list
https://raw.githubusercontent.com/deathislif3/rules/main/rule/Surge/<Category>/<Name>.list
```
